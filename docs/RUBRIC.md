# MATH 101 – Differential Calculus
## Semester Project: Designing a Digital Game Using Differential Calculus

---

## I. Project Overview

Students are tasked with designing and developing an original, functional, and playable digital game inspired by a concept or application of **Differential Calculus**. 

* **Game Nature:** The game can be simple and basic (e.g., racing game, strategy game, simulation, adventure game, or puzzle game) as long as it is functional and operates as intended.
* **Interactivity:** The proposed game must be playable, allowing users to interact with it and experience its intended mechanics.
* **Calculus Integration:** Each group must demonstrate that Differential Calculus plays an **essential role** in the gameplay, player decisions, or game outcomes.
* **Primary Objective:** Apply Differential Calculus concepts and coding skills to develop a functional program that integrates mathematical principles into an interactive online environment. Through this project, students will demonstrate their understanding of calculus by translating theory into practical game mechanics.

---

## II. Project Objectives

By completing this project, students should be able to:
1. **Apply** concepts of Differential Calculus in designing game mechanics and solving in-game challenges.
2. **Develop** a functional and playable online game using appropriate coding techniques.
3. **Demonstrate** how Differential Calculus directly influences player decisions, game mechanics, and outcomes.

---

## III. Project Guidelines & Technical Constraints

### 1. Game Concept and Theme
* Design an original online game with a clear theme, defined objectives, and an identified target player base.
* The game may be inspired by existing games, but its mechanics and application of Differential Calculus must be meaningfully incorporated.
* **Platform:** The proposed game must be designed for a digital platform, such as a computer, mobile device, or web browser.
* **Format Restrictions:** Board games, card games, and other physical games are **strictly not allowed** unless fully adapted into an online, interactive digital format.

### 2. Application of Differential Calculus
* The game must incorporate at least one major concept of Differential Calculus as an essential component of its mechanics (refer to the Course Information Sheet / CIS for topics covered).
* **Critical Rule:** The selected concept must fulfill a meaningful purpose in the game. **Simply adding calculus equations as unrelated trivia or quiz questions is not sufficient.**

### 3. Game Scope and Functionality
* Sophisticated visual effects and high-quality graphics are **not** required. Simple 2D graphics, basic animations, or even text-based interfaces are acceptable, provided the mechanics function as designed.
* The submission must include:
  * A working game interface enabling user interaction.
  * Functional game mechanics, including player actions, objectives, and progression rules.
  * A clear in-engine application of Differential Calculus within the core gameplay loop.
  * Working features demonstrating how calculus concepts govern the challenge, balance, or win/loss conditions.

---

## IV. Required Mechanics Checklist

Each group must explicitly document and present the following:
* **Objective:** What must players accomplish to achieve victory?
* **Platform and Players:** Intended deployment (desktop, mobile, or web browser) and player format (single-player or multiplayer).
* **Rules:** Permitted vs. prohibited actions.
* **Gameplay Sequence:** Turn structure, level progression, or stage loops.
* **Winning / Losing Conditions:** Precise criteria for game-over or victory states.
* **Calculus Mechanics:** At what exact point and by what mathematical formula does Differential Calculus dictate the gameplay?

---

## V. Role of Differential Calculus & Worked Example

> **Note:** This is considered the most critical evaluation component of the project.

Merely displaying equations on-screen is not acceptable. Each group must clearly explain **how** Differential Calculus functions within the game and **why** it matters to player progression.

Your documentation and presentation must provide:
1. **Specific Concept:** Identification of the calculus topic (e.g., optimization, critical points, concavity, related rates, instantaneous velocity/acceleration).
2. **Worked Example:** At least one complete, end-to-end worked example demonstrating how the mathematical concept operates in an actual in-game scenario.
   * Relevant calculus equation(s)
   * Step-by-step mathematical solution (derivatives, tests, or critical values)
   * In-game interpretation
   * Tangible effect on gameplay, player choices, and game balance

---

## VI. Presentation Requirements

Each group will present its proposed online game to the class. All team members must actively participate in the oral presentation and be prepared to answer questions regarding game design, programming logic, and calculus integration.

### Presentation Structure (5 Key Sections):
1. **Game Introduction:** Title, theme, game objectives, and target players.
2. **Game Visualization:** Visual demonstration of the interface, controls, and runtime environment.
3. **Game Mechanics:** Overview of rules, gameplay sequence, and win/loss states.
4. **Differential Calculus Application:** Deep dive into the calculus concept used, accompanied by at least one complete worked example.
5. **Mathematical Significance:** Explanation of how calculus directly drives player decisions, difficulty scaling, and game outcomes.
